✅ NAYI WEBSITE ADD KARNA — STEP BY STEP
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1 — Screenshot lo
  Desktop screenshot (1280×800 pixels):
    → screenshotone.com ya microlink.io/screenshot use karo
    → ya browser me F12 → responsive mode → 1280x800 → screenshot

  Mobile screenshot (390×844 pixels):
    → Chrome DevTools → iPhone 12 mode → screenshot

STEP 2 — Screenshot host karo (free options):
  → Cloudinary.com (free tier, best option)
  → imgbb.com (upload karo, direct link lo)
  → GitHub me image upload karke raw link lo

STEP 3 — PortfolioPage.jsx kholo aur "const projects = [" dhundho

STEP 4 — Last entry ke baad (closing "]" se pehle) ye add karo:

  {
    id:          8,
    title:       "Apki Website Ka Naam",
    description: "Short description jo client ko attract kare — 1-2 sentences.",
    category:    "CATEGORY NAME CAPS ME",
    url:         "https://live-website-url.com/",
    desktopImg:  "https://your-image-host.com/desktop-screenshot.jpg",
    mobileImg:   "https://your-image-host.com/mobile-screenshot.jpg",
  },

⚠️ IMPORTANT: Har entry ke baad comma (,) lagana mat bhoolo
⚠️ id number unique hona chahiye — last id se +1 karo

STEP 5 — File save karo → Vercel automatic deploy karega (~2 min)

   → Terminal: cd frontend && vercel --prod
